
Task 1: Iris Dataset Exploration & Visualization
Objective

To explore the Iris dataset and understand how different flower features relate to each other through basic analysis and visualization.

Dataset
Iris Dataset (Seaborn / CSV)
My Understanding of the Data

Before visualization, I focused on understanding the dataset structure:

Checked number of rows, columns, and feature types
Reviewed sample data using .head()
Verified data types and missing values using .info()
Studied statistical summary using .describe()

This helped me understand how each feature is distributed and how the species differ.

Work Performed
Loaded dataset using Pandas
Performed basic inspection (head, info, describe)
Created visualizations:
Scatter plots for feature relationships
Histograms for distribution analysis
Box plots for outlier detection
Key Insights
Petal features separate species more clearly than sepal features
Setosa is easily distinguishable from other species
Some overlap exists between Versicolor and Virginica
Learning Outcome
Understood step-by-step dataset exploration
Learned importance of visualization before modeling
Improved basic EDA skills using Python
